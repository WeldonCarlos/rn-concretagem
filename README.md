# RN Concretagem

Site institucional em React para apresentação de uma empresa de concretagem, seus serviços e obras.

## O que o projeto apresenta

- Páginas de início, empresa, serviços, obras e contato.
- Navegação com React Router.
- Componentes visuais com Material UI e React Bootstrap.

## Tecnologias

React · JavaScript · Vite · React Router · Material UI · React Bootstrap

## Executar localmente

```bash
git clone https://github.com/WeldonCarlos/rn-concretagem.git
cd rn-concretagem
npm install
npm run dev
```

Abra o endereço informado no terminal.

## Comandos disponíveis

| Comando | Uso |
